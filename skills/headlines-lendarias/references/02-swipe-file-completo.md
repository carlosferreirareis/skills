# Swipe file completo — as headlines lendárias

> Fonte: coletânea "101 Modelos Reais e Traduzidos" — headlines de anúncios reais escritos por copywriters como David Ogilvy, Eugene Schwartz, John Caples, Gary Halbert e Claude Hopkins, entre outros, ao longo do auge da publicidade de resposta direta americana. Tradução para o português ao lado do original em inglês.
>
> **Como usar este arquivo:** é uma lista de referência para buscar por palavra-chave ou tema (dinheiro, saúde, medo, humor, exclusividade...) quando precisar de um ponto de partida. Para entender os *padrões* por trás dessas headlines — o que as torna eficazes e como adaptá-las a um produto novo — leia primeiro `01-formulas-e-padroes.md`. Nunca copie uma headline daqui literalmente para um produto diferente: adapte a **estrutura**, não o texto.
>
> A numeração original da fonte pula do 52 para o 54 (erro de digitação do material original) — preservada aqui por fidelidade.
