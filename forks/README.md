# forks

Skills de terceiros trazidas para este repositório (fork ou adaptação).

Cada skill deve ficar em sua própria pasta, contendo:

- `SKILL.md` — o conteúdo da skill (original ou adaptado).
- `SOURCE.md` — origem: link do repositório/gist/autor original, licença e um resumo do que foi alterado em relação ao original.

Respeite sempre a licença do projeto de origem.
